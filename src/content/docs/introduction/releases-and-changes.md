## Releases & Changes

Check the [GitHub releases page](https://github.com/hikmahealth/hikma-health-server/releases) for the latest updates and changelog entries.

The same Releases page also publishes the installers for the [Local Sync Hub](/docs/local-sync-hub/overview) desktop app (macOS, Windows, and Linux bundles). Once installed, the hub checks that page for new versions and updates itself in place — see [Operating the Hub](/docs/local-sync-hub/operating-the-hub#auto-updates).
