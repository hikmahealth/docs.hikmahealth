## Try the demo

You can test the Hikma Health EHR system without deploying it yourself. Follow the steps below to get started.

### 1. Sign into the dashboard

Go to [https://hikma-health-server.onrender.com](https://hikma-health-server.onrender.com) and sign in with the following test credentials:

- **Email:** test-user@hikmahealth.org
- **Password:** HikmaTester4

### 2. Activate the app

Once signed in, click **"Activate app"** to generate a QR code. You can find this in **Settings > Mobile Apps**.

### 3. Download the mobile app

- **Android:** Download from the [Google Play Store](https://play.google.com/store/apps/details?id=com.hikmahealth.hikma_health)
- **iOS:** Download from the [Apple App Store](https://apps.apple.com/us/app/hikma-health/id1546761242)

### 4. Register your device

Open the mobile app and select **"Register app with QR code"**, then scan the QR code displayed on the administrator dashboard.

### 5. Sign in on the mobile app

Use the same test credentials to sign in. After logging in, you can register patients, document visits, and explore other platform features.

### Troubleshooting

If you run into issues, check the browser console and server logs for error details. If you're stuck for more than 15 minutes, [file an issue on GitHub](https://github.com/hikmahealth/hikma-health-app/issues) or send us an email with a detailed description of the problem and screenshots if possible.
